# Глава → курс: конвейер g2k

Конвейер превращает главу книги по геологии или геофизике в проверенный демо-курс для новичка.
Порядок работы фиксирован: **учебный слой → маршрутизация → спецификация сцены → курс и ролики**.
Учебный слой — единственный источник правды: курс, задания, иллюстрации и ролики собираются из него.

## Как открыть готовый курс
Откройте `out/<глава>/course/index.html` двойным щелчком. Сервер и логин не нужны.
Курсы: `out/latyshova/course/index.html`, `out/basniev/…`, `out/kuznetsov/…`.

## Как запустить конвейер

```powershell
pip install -r requirements.txt
cd tools; npm install; cd ..          # KaTeX для формул офлайн (один раз)
python run.py build latyshova          # одна команда на главу: слой → покрытие → маршрутизация → задания → иллюстрации → курс
python run.py video latyshova          # шортс 9:16 по узлу из маршрутизации (--aspect 16:9 — разбор)
python run.py check latyshova          # проверка всех файлов по общим схемам и цитат по правилу жюри
python run.py review <package.json> --md <глава.md>   # модуль проверки чужого пакета
```

Новая глава (например, тестовая) — одна запись, код не меняется:

```powershell
python run.py add-chapter --key test1 --md путь\к\главе.md --pages 10-25 --prefix test1 --book "Автор. Книга, гл. N" --lang en
python run.py build test1
```

Новый домен (сдвиг, например бурение) — пакет собирается автоматически по главе:

```powershell
python run.py domain-bootstrap drilling --from-chapter test_shift
python run.py build test_shift
```

## Правка факта и пересборка одной командой
Ручная правка — только через `patches/<глава>.json`, чтобы она пережила пересборку и попала в журнал:

```json
[{"target": "latyshova.mud_properties#c3", "field": "text", "value": "исправленный текст", "minutes": 2, "reason": "число с соседней страницы"}]
```

Затем `python run.py build latyshova --stage course` (курс) и `python run.py video latyshova --node <узел>` (ролик).
Ответы модели кешируются (`.cache/llm`), поэтому пересборка не тратит запросы и даёт тот же результат.

## Модель заменяема
Все обращения к модели — в `g2k/llm.py`, выбор в `.env` (см. `.env.example`):
- `claude-code` — Claude Code по подписке (по умолчанию, если нет ключа API);
- `api` — Anthropic API по ключу;
- `openai` — любая локальная модель через vLLM / Ollama / LM Studio (`LLM_BASE_URL`).

## Что где лежит
| Путь | Что |
| --- | --- |
| `run.py` | точка входа, все команды |
| `g2k/chapter.py` | нарезка главы по `<!-- page N -->` на единицы покрытия `p095.03` |
| `g2k/quotes.py` | проверка цитат по правилу жюри и авторемонт почти дословных цитат |
| `g2k/layer.py` | учебный слой: план узлов с покрытием → узлы → проверка кодом |
| `g2k/route_tasks.py` | маршрутизация (детерминированно) и задания с проверкой ответа по тексту шага |
| `g2k/illus.py` | SVG-схемы по шаблону на тип трудности, метка происхождения на картинке |
| `g2k/course.py` | курс одним HTML-файлом |
| `g2k/video.py` | ролик: спецификация → инварианты → озвучка → кадры из модели состояния → MP4 + паспорт |
| `g2k/review.py` | модуль проверки: обвинение только с дословной цитатой + скептический второй проход |
| `g2k/bootstrap.py` | доменный пакет для нового домена |
| `domain/geo/` | доменный пакет: глоссарий RU/EN, заблуждения, чек-лист физики, ИТ-мосты, стайлгайд, словарь произношений |
| `schemas/` | общие схемы организаторов |
| `out/<глава>/` | `layer.json`, `coverage.json`, `routing.json`, `tasks.json`, `illustrations.json`, `course/` |
| `out/metrics.csv` | токены, время, стоимость по этапам — пишется автоматически |
| `manual_edits.csv` | журнал ручных правок |
| `MANIFEST.md` | модели, инструменты, что уходит наружу |

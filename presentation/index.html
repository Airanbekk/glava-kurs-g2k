Ставка: точность встроена в код, а не в промпт

  • Модель пишет — код проверяет. Каждое утверждение несёт дословную цитату и страницу; код сверяет её с главой по правилу жюри. Не прошло — утверждение не выходит.
  • Покрытие считает код, а не модель. Глава режется на единицы p095.03; каждая единица — в узле или с причиной.
  • Курс и ролики собираются из слоя. Ошибку правят в одном месте — всё пересобирается одной командой.
  • Без картинок «на глаз». Схемы и кадры рисует код из утверждений и модели состояния; генерации фактов нет.

4/10

Курс, который новичок проходит сам

  • Один HTML-файл ~1,5 МБ: открывается без сервера и логина, телефон 390 px и десктоп, тёмная и светлая тема, формулы офлайн
  • Страница шага: заголовок для новичка, суть в 2–3 фразах, «как это работает» со «стр. N» у каждого абзаца (клик — цитата автора), разборы примеров с числами автора, цифры и условия, формулы с расшифровкой, таблицы книги, частая ошибка, «что это значит для данных», ИТ-аналогия и где она ломается
  • Поля модели помечены «пояснение модели» / «гипотеза» — видно автора и модель
  • Задания 5 типов (один ответ, несколько, порядок перетаскиванием, пропуски, расчёт), проверка сразу; ответ гарантированно есть в тексте шага — это проверяет код
  • Карточки «знаю / повторить», конспект с печатью в PDF, карта связей шагов
5/10

Ролики: кадр утверждает — значит, его считает код

  • Шаблон на тип трудности: прибор опускается по стволу, кривая считается из той же модели пласта — глубина прибора управляет и его положением, и точкой кривой
  • Инварианты проверяет код: пласты без дыр, газ над нефтью над водой, глубина растёт вниз; метка «симуляция» на каждом кадре; преувеличения подписаны
  • Голос не говорит больше источника: каждая фраза ссылается на утверждение; всё, о чём говорит голос, видно в кадре
  • Крючок → механизм → пауза на предсказание → ответ → вопрос на перенос; субтитры; −16 LUFS; 110–130 слов/мин; синхрон голос–кадр по построению
  • Озвучка: Microsoft Neural, запасной офлайн-голос Windows — наружу только текст сценария
6/10

Модуль проверки: находить ошибки, не трогая верное

95% ошибок по весу, 0 ложных тревог (контрольный пакет, скрипт организаторов)

  • Барьер 1: обвинение только с дословной цитатой главы, которая противоречит элементу; цитату проверяет код
  • Барьер 2: скептический второй рецензент пересматривает каждое замечание
  • Барьер 3: порог уверенности
  • Детерминированные сигналы: цитата не на своей странице, числа без опоры
  • Кадры проверяются по изображению: метка, класс, глубина, порядок флюидов
7/10

Перенос: новая глава, новый домен, новая модель

  • Новая глава — одна запись в chapters.json, код не меняется: add-chapter … && build
  • Новый домен (сдвиг, бурение): доменный пакет собирается автоматически по главе за минуты — domain-bootstrap drilling; пакет отдельно от движка
  • Модель заменяема одной строкой в .env: Claude по API, Claude Code по подписке или локальная модель компании через vLLM / Ollama — для прогона 300+ книг
  • Глава на английском: цитаты остаются в оригинале, курс по-русски, глоссарий RU/EN
8/10

Ручной труд и стоимость — в цифрах

  • Ручные правки только через patches/<глава>.json: правка переживает пересборку и сама попадает в журнал с минутами
  • Журнал совпадает с историей коммитов по построению
  • Ответы модели кешируются: пересборка после правки факта — одна команда, бесплатно и детерминированно
  • Метрики по главам и этапам: токены, деньги, время → стоимость узла и главы для масштабирования

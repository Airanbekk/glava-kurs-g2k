# Тестовый этап: главы и ролики

Книги выданы целиком в md. Обрабатывать нужно только указанные главы. Страницы — по меткам `<!-- page N -->` в md-файле. PDF дан для просмотра рисунков; номера страниц PDF могут не совпадать с метками md (у Asquith сдвиг на одну страницу), поэтому в слое, курсе и паспортах ролика ссылайтесь на страницы по меткам md.

# Словарь произношений

| Пишется | Читается | Расшифровка |
| --- | --- | --- |
| ГНВП | гэ-эн-вэ-пэ | газонефтеводопроявление |
| АВПД | а-вэ-пэ-дэ | аномально высокое пластовое давление |
| СПО | эс-пэ-о | спускоподъёмные операции |
| ПВО | пэ-вэ-о | противовыбросовое оборудование |
| ГТИ | гэ-тэ-и | геолого-технологические исследования |
| КНБК | ка-эн-бэ-ка | компоновка низа бурильной колонны |
| НКТ | эн-ка-тэ | насосно-компрессорные трубы |
| ЭЦП | э-цэ-пэ | эквивалентная циркуляционная плотность |
| Рбт | пэ бэ тэ | давление в бурильных трубах при закрытой скважине |
| Ркп | пэ ка пэ | давление в кольцевом пространстве при закрытой скважине |
| pпл | пэ пэ-эль | пластовое давление |
| pзаб | пэ забойное | забойное давление |
| МПа | мегапаскаль | единица давления, 1 МПа ≈ 10,2 кгс/см² |
| л/с | литров в секунду | единица расхода раствора |
| СНС | эс-эн-эс | статическое напряжение сдвига |
| ДНС | дэ-эн-эс | динамическое напряжение сдвига |
| H₂S | аш-два-эс | сероводород |
| ΔVmin | дельта вэ минимальное | минимальный обнаруживаемый объём притока |
| SIDPP / SICP | си-ай-ди-пи-пи / си-ай-си-пи | зарубежные обозначения давления в трубах и в кольцевом пространстве при закрытой скважине (эквиваленты Рбт и Ркп) |
